# AI-READWRITE: 对话记忆沉淀

> 本文件为 **可写档案**：AI 每次对话结束后，自动把新经验、新偏好**追加**到文末，
> 只新增内容，不覆盖、不删除原有记录。

## 写入规则

每次对话结束后，自动提取并追加：

1. 新增个人偏好
2. 新的经验教训
3. 临时需求与长期诉求
4. 重要事实（职业变动、健康、关系、财务等）
